# TigerSB-panel

Автономная панель для своей VPN-сети на Xray: VLESS через gRPC и XHTTP, каскад по gRPC, XHTTP через Yandex Cloud CDN, TUIC напрямую и через каскад.

Работает в паре с клиентом [TigerSB-client](https://github.com/Stilltiger45/TigerSB-client) для Android и Windows: пользователь вставляет одну уникальную ссылку из панели и подключается.

Сейчас готов первый этап: каркас панели, вход по логину и паролю, установщик с выбором роли и режим сна. Протоколы появятся на следующих этапах.

## Установка

На чистом сервере (Debian или Ubuntu с systemd, amd64 или arm64), от root:

```bash
git clone https://github.com/Stilltiger45/TigerSB-panel.git
cd TigerSB-panel
sudo ./scripts/install.sh
```

Установщик спросит:

1. **Роль сервера.** «Основной сервер» выпускает трафик в интернет и держит панель. «Точка маршрутизации» принимает подключения и пересылает их на основной сервер по каскаду.
2. Для основного сервера: домен и email для сертификата. Для точки маршрутизации: адрес основного сервера.
3. Логин и пароль администратора (пароль не короче 10 символов).

Если Go на сервере нет, установщик сам скачает его для сборки. Когда появятся релизы, можно будет передать готовый бинарник: `sudo ./scripts/install.sh --binary ./tigersb-linux-amd64`.

## Вход в панель

Панель слушает только `127.0.0.1` на случайном порту и открывается по секретному пути. Нужно и то, и другое одновременно:

```bash
# на своём компьютере
ssh -N -L 8080:127.0.0.1:<порт> root@<сервер>
```

Пока туннель открыт, откройте `http://localhost:8080/<секретный путь>/` и войдите. Порт и путь показывает команда `tigersb info` на сервере. Любой другой путь отвечает 404.

## Клиент и уникальная ссылка

Для каждого пользователя панель выдаёт свою уникальную ссылку. Её достаточно вставить в [TigerSB-client](https://github.com/Stilltiger45/TigerSB-client) или отсканировать QR-код, и VPN подключится:

```
tigersb://add?url=https://<домен>/sub/<токен пользователя>&pk=<ключ подписи панели>&name=<имя>
```

- `url` — адрес подписки пользователя. Токен случайный и у каждого свой, поэтому ссылку можно отозвать или выпустить заново, не трогая остальных.
- `pk` — публичный ключ Ed25519 панели. Панель подписывает каждый профиль, а клиент принимает только профиль с этой подписью, поэтому подменить серверы по дороге нельзя.
- `name` — название, которое клиент покажет пользователю.

По адресу подписки панель отдаёт подписанный профиль: выходы (основной сервер и точка маршрутизации), транспорты (gRPC, XHTTP, XHTTP через Yandex CDN) с приоритетами и списки маршрутизации. Формат описан в [docs/profile.md](https://github.com/Stilltiger45/TigerSB-client/blob/main/docs/profile.md) клиента. Панель собирает и подписывает профиль пакетом `pkg/profile` из репозитория клиента, поэтому формат у них общий.

Клиент при каждом обновлении присылает заголовки `x-hwid`, `x-device-os` и `x-device-model`. По ним панель считает устройства на подписке и не выдаёт профиль сверх лимита.

Пока панель усыплена, подписки продолжают работать: Caddy отдаёт их из готовых файлов. Лимит устройств в это время не проверяется и снова работает, когда панель проснётся.

Выдача ссылок, подписок и лимит устройств появятся на следующих этапах вместе с протоколами.

## Команды на сервере

| Команда | Что делает |
|---|---|
| `tigersb info` | показать команду туннеля и адрес панели |
| `tigersb passwd --admin <логин>` | сменить пароль, все сессии завершаются |
| `tigersb sleep` | усыпить панель: процесс остановлен, туннель и секретный путь не помогут. VPN и подписки продолжают работать |
| `tigersb wake` | разбудить панель |
| `tigersb status` | состояние панели |

## Защита входа

- Пароли хранятся как Argon2id, сессии как SHA-256 от токена.
- Cookie `HttpOnly`, `SameSite=Strict`, только для секретного пути. Сессия живёт 12 часов.
- После 5 неудачных попыток логин блокируется на 15 минут, после 30 попыток в сумме блокируется весь вход.
- Запросы на изменение принимаются только как JSON с того же источника.

## Разработка

```bash
go test ./...
CGO_ENABLED=0 go build -o tigersb ./cmd/tigersb
```

Тег `v*` собирает релиз с бинарниками `tigersb-linux-amd64` и `tigersb-linux-arm64`.
