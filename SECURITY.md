# Безопасность

О найденной уязвимости сообщайте приватно: GitHub → вкладка Security → Report a vulnerability. Публичные issue для этого не используйте.

Что считается уязвимостью: обход входа, доступ к панели без SSH-туннеля и секретного пути, утечка паролей, ключей подписи или токенов подписок, подмена подписанного профиля.

Поддерживается последняя версия из ветки `main`.
